# Game shop artwork

Original transparent item illustrations generated with the built-in image generation tool (not the CLI). Saved assets:

- `client/public/game-items/landmine.png`
- `client/public/game-items/ink-bomb.png`

Used by the `GAME_BOOSTERS` registry and shop cards/inventory. The interface takes inspiration from collectible strategy-game shops; the artwork was generated as original items.

## Final prompts

### landmineArt

Use case: stylized-concept. Asset type: original classroom game shop item illustration, square transparent PNG. A single chunky whimsical LANDMINE gadget: squat circular brass-and-dark-navy mechanical pressure plate, oversized orange glowing center, four large bolts, thick beveled metal rim, playful toy-like proportions and a few small angular floating sparkles. Three-quarter view from above, centered and fully visible occupying 75% of the canvas. Premium hand-painted mobile strategy game item rendering with confident shapes, crisp silhouettes, tactile painted metal, rich amber highlights, navy shadows, subtle rim light. Designed to read clearly at 150 pixels. Standalone object on genuinely transparent background. No floor, no frame, no text, no lettering, no logos, no watermark, no characters, no photorealistic weapon details. This is an original cartoon classroom sabotage game icon.
