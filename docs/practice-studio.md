# Practice and video studio

Open **Teacher Study Hall → Practice & video studio**, or use **Manage practice & videos** on a math topic. The studio is at `/teacher/practice-studio`.

## Organize practice

- **Practice modules:** add or duplicate a module, edit its title and description, choose its math category/topic, and check its question generators. Use the arrow buttons to reorder modules. Uncheck Published to hide a module from students.
- Foundation Building supports contained modules. On an individual module, choose **Module placement → Inside Foundation Building**. Move it out to restore a separate listing. The collection’s **Contained modules** controls let teachers publish/hide its children. Student lists show only the parent module; its **Settings** let students choose which contained modules to include in a session.
- **All Question Types** always includes every enabled generator. Students use its **Settings** to choose topics. Other mixed modules may opt into all enabled generators. Generators carry a category/topic for these filters.
- **Question generators:** Add generator creates an editable inequality template. Choose one-step or two-step, set coefficient/solution/constant ranges, and include negative coefficients or inclusive inequalities. **Preview a generated question** opens the existing exam player with the current draft. Answer and use Next to check a response, then Next again for another question. Use **User menu → Close preview** or Escape to return to the studio. Preview answers stay separate from saved practice sessions and do not publish draft edits. Generator IDs are stable; a generator can belong to several modules.
- After adding a generator, select the desired modules and check it in their generation sets. Saved changes apply to new sessions. Running sessions store their module title and generator definitions so edits do not change questions midway through practice.
- **Delete generator** removes it from the library and all module references. Empty individual modules are hidden. Deletion is staged until Save changes, with an Undo deletion option; running sessions retain their original snapshot.
- **Save changes** saves the catalog centrally. Published modules appear in their topic's existing scrollable Infinite Practice box. Launching a module opens the existing exam player directly. The student home page now shows the same module box above the exam countdown. Per-student module/topic choices are stored on the current device and do not change the teacher catalog.

The editable template library currently supports one-step and two-step linear inequalities. New mathematical families need a supported template; organizing modules, mixing existing generators, and adjusting supported templates require no code.

**Inequalities: Variables on Both Sides** is a built-in module under **Algebra → Inequalities**, based on `2022-2023-form-b-q70` (`2x + 11 > 3x + 9`). It varies both coefficients and constants, covers both strict inequality directions and sign flips, and provides four choices with worked explanations. Each seeded cycle contains 133,200 distinct stems with integer solution boundaries before repeating; practice continues across cycles. New catalogs include it automatically. For an existing saved catalog, run `node tools/register-q70-practice.cjs` to preview registration, then append `--apply` to add the generator and its module with a revision check. Registration preserves existing resources and is safe to rerun.

**Writing Inequalities** is based on `2026-2027-form-d-math-item-26`. Students enter an inequality for a rental budget with an hourly rate and a one-time fee. Its 93,312-stem cycles vary the rental, name, rate, fee, and budget. The expression keypad includes `x`; accepted answers cover both term orders, reversed inequalities, and common notation. Feedback shows one model answer and explains why the budget allows equality. New catalogs include it automatically; use `node tools/register-writing-inequalities.cjs` to preview registration in an existing catalog and append `--apply` to save.

Practice and generator previews share green/red result indicators, answer feedback, and a toolbar showing the current streak, best streak for the session, and accuracy. A wrong answer resets the current streak while retaining the best. The existing pencil toolbar stays above the player overlay and provides Undo, Redo, and Clear pencil marks.

## Curate references

**YouTube videos** lets teachers add a title, description, video link, category, and topic. Valid HTTPS YouTube watch, Shorts, embed, live, and youtu.be video links are normalized to a watch URL. Draft references may have a blank link; published ones require a valid video. Publish and reorder references to show compact thumbnail-and-title rows in the topic's YouTube Videos box beside Worksheets and Infinite Practice. Clicking a row opens a video player inside Study Hall; no separate outbound YouTube link is added. Closing the player or pressing Escape stops playback and returns to the list. Thumbnails load from YouTube's image CDN, with a play-icon fallback if unavailable. **Video details (optional)** provides a channel name, duration badge, view count, and publication date; omitted details are hidden. Dates display relative to today. These details are teacher-curated; the app does not scrape video metadata. The privacy-enhanced YouTube embed is loaded only after a student clicks Play. It is sandboxed without popup or top-navigation permissions. YouTube still controls its own player branding and controls.

## Storage and permissions

Apply `supabase/migrations/202610260004_practice_catalog.sql`. It was applied to the configured Supabase project on October 26, 2026. The application uses the single `infinite_practice_catalog` row with revision checks. Initial reads use the built-in starting catalog until the first save; database failures return an explicit error, never an ephemeral file fallback. Saving from an outdated window returns 409 and preserves the saved catalog.

`GET /api/infinite-practice/catalog` requires an authenticated SHSAT student or teacher/admin. Students receive published modules/videos and enabled generators. `GET ...?manage=1` and `PUT /api/infinite-practice/catalog` require teacher/admin access verified from app metadata. The table has RLS enabled, with browser database roles denied direct access. The server validates taxonomy, references, IDs, bounded integer generator settings, and nonempty published generation sets.

`npm run test:practice-studio` covers generator correctness, snapshots, links, permissions, revision conflicts, persistence behavior and Study Hall rendering. `node tools/preview-study-hall.cjs --port=4347` provides an isolated fictional studio and student view with in-memory data; it never reads credentials or changes real accounts.
